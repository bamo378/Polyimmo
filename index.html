Connexion GitHub

Les saisies sont enregistrées dans le fichier data/entries.json de votre dépôt. Il faut une clé d'accès GitHub (à faire une seule fois, sur chaque appareil) :

  1. Sur github.com : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « Site PolyImmo » · Expiration : 1 an · Repository access : Only select repositories → Polyimmo.
  3. Permissions → Repository permissions → Contents : Read and write. Générez, copiez la clé (commence par github_pat_) et collez-la ici.

La clé reste uniquement dans ce navigateur. Elle n'est jamais envoyée ailleurs qu'à GitHub.
